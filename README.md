# Numbers and ABC Corner

Maths and English practice for Class 2 to 5. Built by **Gnaneswar**.

A friendly practice app for children that works on phones and computers.

## What's inside

Pick a class (2, 3, 4 or 5) and the questions get harder to match it.

**Maths:** Addition · Subtraction · Multiplication · Division · Place value · Word problems
**English:** Spelling (listen and choose) · Missing letter · Opposites · Plurals · Word types (noun / verb / adjective / adverb) · ABC order

- 10 questions per round, with new random questions every time
- 🔊 Speaker buttons read questions and words aloud
- ⭐ One star for each right answer. Stars and best scores are saved on the device
- Works offline and can be added to the home screen like an app

## How to use it

**Quickest:** download `index.html` and open it in any browser.

**Put it online for free (GitHub Pages):**
1. In this repository on GitHub, go to **Settings → Pages**.
2. Under "Build and deployment", choose **Deploy from a branch**, pick the branch and the `/ (root)` folder, then click **Save**.
3. After a minute your app will be at `https://<your-username>.github.io/<repo-name>/`.
4. Open that link on a phone and choose **Add to Home screen** to install it like an app.
