# Numbers and ABC Corner

A Maths and English learning app for Class 2 to 5.

**Built by Gnaneswar.**

## What's inside

- **Maths, Learning Zone:** Number Explorer, Practice Quiz, Times Tables, Fraction Lab, Clock and Time, Money, Speed Maths.
- **Maths, Advanced Topics:** step-by-step long multiplication, long division, fractions, decimals, HCF and LCM.
- **English, Learning Zone:** Letter Sounds, Say It Right, Word Builder, Sentence Builder.
- **English, Advanced Topics:** 40 grammar topics with at least 50 examples each, Telugu explanations for parts of speech and tenses, and 5-question practice sets.

Every screen changes with the class (2, 3, 4 or 5). An "All classes together" section opens every class's Maths or English in one place.

## Install it on a phone

**Option 1: from the browser (recommended).** Open the app link in Chrome on Android and choose **Install app** (or menu ⋮ → **Add to Home screen**). It then works offline, and read-aloud uses the phone's voice.

App link (after GitHub Pages is turned on): `https://nclind09-gnan.github.io/Kids-learning-/`

**Option 2: APK file.** Every push to `main` builds an Android APK automatically. Open the **Releases** page of this repository, download `ABC-Corner.apk`, and open it on the phone. Android will ask you to allow installing apps from your browser or file manager the first time.

## Files

- `index.html`: the whole app (one file)
- `manifest.webmanifest`, `sw.js`, `icons/`: make it installable and work offline
- `.github/workflows/android-apk.yml`: builds the APK with Capacitor
